# لوحة مبيعات Total

لوحة عربية RTL ثابتة (HTML/CSS/JS + Chart.js من cdnjs) تقرأ `data/sales-data.json`. لا تحتاج خادمًا ولا مفاتيح.

## المحتويات
- `index.html`, `styles.css`, `app.js`: اللوحة.
- `data/sales-data.json`: بيانات ورقة Target (المستهدف والفعلي لكل شهر وفئة، 2024–2026) + تنبيهات جودة البيانات.
- `tools/build_json.py`: يعيد توليد JSON من Excel.

## الخصوصية
الملف يحتوي أرقامًا مجمّعة فقط، بلا أسماء عملاء أو جوالات. لا تضف بيانات العملاء إلى مستودع عام.

## تحديث البيانات
1. عدّل ورقة Target في Excel، واحفظ نسخة بصيغة xlsx.
2. `python tools/build_json.py Total_2026.xlsx`
3. حدّث الحقل `asOf` في JSON، ثم ارفع التغيير.

## التشغيل محليًا
`python -m http.server 8000` ثم افتح http://localhost:8000 (فتح الملف مباشرة لا يعمل بسبب fetch).

## النشر
GitHub → Settings → Pages → Branch: main، المجلد root. (يُنصح بمستودع خاص إن أضفت بيانات عملاء؛ Pages للمستودعات الخاصة يتطلب خطة مدفوعة.)

## ملاحظات على البيانات
- الأشهر التي فعليها فارغ أو صفر لكل الفئات تُعدّ «غير مؤكدة» وتُستثنى من نسبة التحقيق، ولا تُعامل كمبيعات صفرية.
- نسبة التحقيق (الفعلي ÷ المستهدف) غير نسبة النمو.
- وحدة القياس غير مذكورة في المصدر.
